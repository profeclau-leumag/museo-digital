CONCEPTO

¿Qué es la World Wide Web?

La World Wide Web (WWW) es un sistema de información que funciona sobre Internet y permite acceder a documentos y recursos mediante enlaces.

Para funcionar utiliza tecnologías fundamentales como HTML, HTTP y URL, que permiten estructurar, solicitar y localizar información.

¿Por qué fue necesaria?

Antes de la Web, los investigadores tenían dificultades para compartir información entre diferentes sistemas y computadoras.

PRIMEROS AÑOS

Los primeros años de la Web

Los acontecimientos que marcaron el comienzo de la World Wide Web.

1989 La propuesta +

Tim Berners-Lee propone en el CERN un sistema que permitiera compartir información de una manera más sencilla entre investigadores.

La idea consistía en conectar documentos mediante enlaces para que pudieran ser consultados desde diferentes computadoras.

1990 La primera página Web +

Durante este año se desarrollan las primeras herramientas necesarias para que la Web pueda funcionar.

También aparece la primera página web, creada en el CERN, junto con el primer servidor y navegador.

1991 La Web comienza a expandirse +

El proyecto empieza a estar disponible para otras personas fuera del equipo original.

Poco a poco aparecen nuevos servidores y la idea comienza a extenderse entre universidades y centros de investigación.

1993 Una Web abierta +

El CERN decide permitir que la tecnología de la Web pueda utilizarse libremente.

Esta decisión facilita que más personas, instituciones y empresas puedan adoptar la tecnología y contribuye enormemente a su expansión.

PERSONAS

Las personas detrás de la Web

Dos de las figuras fundamentales en el desarrollo de la World Wide Web.

1955 · PRESENTE

Tim Berners-Lee

Científico de la computación británico, considerado el creador de la World Wide Web.

En 1989, mientras trabajaba en el CERN, presentó una propuesta para crear un sistema que facilitara el intercambio de información entre investigadores.

Su trabajo dio origen a tecnologías como HTML, HTTP y las URL, elementos fundamentales para el funcionamiento de la Web.

1947 · PRESENTE

Robert Cailliau

Ingeniero e informático belga que trabajó junto a Tim Berners-Lee en los primeros años de la Web.

Participó en el desarrollo y difusión del proyecto dentro del CERN, ayudando a convertir la propuesta inicial en un sistema funcional.

También tuvo un papel importante en la presentación y promoción de la Web durante sus primeras etapas.

COMPUTACIÓN

¿Cómo funciona la Web?

Varias tecnologías trabajan juntas para mostrar una página en el navegador.

URL

URL

Identifica la ubicación de un recurso en la Web.

HTTP

HTTP

Permite que el navegador solicite recursos al servidor.

HTML

HTML

Organiza la estructura y el contenido de una página.

WWW

Navegador

Interpreta los recursos y muestra la página al usuario.

Ejemplo: El usuario introduce una URL → el navegador realiza una solicitud HTTP → el servidor responde → se recibe HTML → el navegador muestra la página.

LEGADO

Una idea sencilla con un impacto enorme.

La World Wide Web facilitó enormemente el acceso y el intercambio de información.

Su sistema de documentos, enlaces y servidores permitió que la información pudiera consultarse de manera sencilla desde diferentes lugares.

05

LIMITACIONES

Una tecnología en evolución

En sus primeras etapas, la Web tenía capacidades multimedia y de diseño muy limitadas en comparación con las páginas actuales.

Las primeras páginas eran principalmente estáticas y estaban orientadas a mostrar documentos y permitir la navegación mediante enlaces.

La interacción avanzada y el contenido dinámico aparecieron posteriormente con nuevas tecnologías.
