# Museo Digital del Curso

Sitio colaborativo para construir un museo de la historia de la computación. Cada estudiante o pareja trabaja únicamente dentro de su carpeta en `cuadros/` y propone su aporte mediante una rama y un *pull request*.

## Vista local

Abre `index.html` en un navegador. Para practicar en [Codi.link](https://codi.link/), copia por separado el contenido de `index.html`, `estilos.css` y `script.js` en los paneles HTML, CSS y JavaScript.

## Flujo de trabajo

1. Busca tu número y tema en `ASIGNACION.md`.
2. Crea una rama con el nombre `cuadro-XX-apellido`.
3. Edita solamente `cuadros/XX-tema/index.html` y `cuadros/XX-tema/estilos.css`.
4. Prueba la página y revisa la pauta.
5. Haz un commit descriptivo: `Agrega cuadro XX sobre ...`.
6. Abre un *pull request* hacia `main`.
7. Atiende las observaciones antes de fusionar.

## Regla para evitar conflictos

No edites `index.html`, `estilos.css`, `script.js` ni las carpetas de otras personas, salvo indicación de la profesora.

## Requisitos mínimos de cada cuadro

- título, fecha o período y autoría;
- una pregunta histórica respondida: qué problema resolvía;
- explicación breve de cómo funcionaba;
- una limitación o tensión;
- legado o relación con la computación actual;
- una imagen con texto alternativo y crédito;
- dos fuentes confiables enlazadas;
- declaración transparente del uso de IA;
- HTML semántico y CSS propio, legible en computador y celular.

## Publicación

La profesora revisa los *pull requests*, integra los cuadros aprobados y puede publicar el repositorio con GitHub Pages desde la configuración del repositorio.
